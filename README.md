## 📐 Математика и валидация сделок

При поиске и перепродаже внутриигровых предметов критически важно учитывать комиссию торговой площадки и ликвидность лота:

### 1. Выплата продавцу с учетом комиссии площадки
Комиссия площадки ($F$, по умолчанию $15.0\%$) вычитается из медианной цены продажи лота ($P_{\text{median}}$):
$$\text{Payout} = P_{\text{median}} \times \left(1 - \frac{F}{100}\right)$$

### 2. Чистая прибыль в рублях
Чистая прибыль ($\text{Net Profit}$) отражает реальный финансовый результат после уплаты всех сборов:
$$\text{Net Profit} = \text{Payout} - P_{\text{buy}}$$

### 3. Процент доходности (ROI)
Маржинальность рассчитывается строго относительно затраченного капитала на покупку лота ($P_{\text{buy}}$):
$$\text{ROI (\%)} = \left(\frac{\text{Net Profit}}{P_{\text{buy}}}\right) \times 100\%$$

*Сделка считается потенциально выгодной, если $\text{ROI} \ge \text{MIN\_PROFIT\_PERCENT}$ (по умолчанию $15.0\%$).*

### 4. Фильтр ликвидности
Даже при высокой теоретической марже предмет может «зависнуть» на балансе, если нет покупателей. Фильтр отсекает лоты с недостаточным объемом торгов:
$$\text{Is Liquid} \iff \text{Sales}_{\text{24h}} \ge \text{MIN\_SALES} \quad (\text{по умолчанию } \ge 15 \text{ сделок в сутки})$$

## 🚀 Быстрый старт

### 1. Клонирование и настройка окружения
Для работы требуется Python 3.14+:

```bash
# Создание виртуального окружения
python3.14 -m venv .venv

# Активация окружения (macOS / Linux)
source .venv/bin/activate

# Установка зависимостей
pip install -e ".[dev]"
# или: pip install httpx pydantic-settings rich pytest pytest-asyncio ruff
```

### 2. Настройка конфигурации (.env)
Создайте файл `.env` в корне проекта (на основе шаблона `.env.example`):

```bash
cp .env.example .env
```

Параметры конфигурации:
```env
TELEGRAM_BOT_TOKEN="1234567890:ABCdefGHIjklMNOpqrsTUVwxyz" # Токен бота от @BotFather
TELEGRAM_CHAT_ID="987654321"                               # ID вашего чата или пользователя
MIN_PROFIT_PERCENT=15.0                                    # Мин. чистая прибыль (%)
MARKET_FEE_PERCENT=15.0                                    # Комиссия площадки (%)
CHECK_INTERVAL_SECONDS=2.0                                 # Период опроса рынка (сек)
```

## 💻 Запуск и режимы работы

### 1. Проверка связи с Telegram (`--test-alert`)
Отправляет одну тестовую карточку лота в Telegram по данным из `.env` и выводит подробный статус в консоль:

```bash
python main.py --test-alert
```

Пример вывода:
```text
🔔 Проверка связи с Telegram...
• Токен бота: 9208025994...
• Chat ID: 5132243439
✔ УСПЕХ: Карточка успешно доставлена в Telegram (message_id: 2)
```

### 2. Разовый снимок рынка (`--once`)
Опрашивает площадку один раз, строит цветовую таблицу лотов и панель метрик без входа в бесконечный цикл:

```bash
python main.py --once
```

### 3. Живой терминальный дашборд (Live Monitor)
Запускает непрерывный мониторинг в реальном времени (`rich.live.Live`):

```bash
python main.py
```
*Для безопасной остановки монитора нажмите `Ctrl+C` (завершается корректно без стектрейса).*
